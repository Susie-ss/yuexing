# 阅行 · 网页自动阅读

> 让阅读，顺流而下。

一个轻量的 Chrome / Edge 浏览器扩展。打开长文章或本地 HTML 后，阅行会按你设定的速度自动滚动；阅读时只在页面角落留下一个小图标，随时可以展开控制。

## 功能

- **自由调速**：5–140 px/s，附带舒缓、标准、速读预设。
- **悬浮迷你控件**：开始后扩展弹窗关闭，页面角落只保留一个小图标；点击图标可展开控制面板，支持暂停、继续、停止、打开扩展正式窗口和关闭退出，也可拖动控件。
- **循环阅读**：到达页面底部后回到顶部继续阅读。
- **平滑滚动**：滚动更连贯，适合长文阅读。
- **识别滚动容器**：尝试在文章区域和页面之间自动找到可滚动内容。
- **手动优先**：滚轮或方向键、空格、Page Up / Page Down 等手动操作会暂停自动滚动。
- **本地保存设置**：速度、循环和平滑选项保存在浏览器本地。
- **键盘快捷键**：`Alt + Shift + R` 开始/暂停，`Alt + Shift + S` 停止。

## 安装

1. 下载本项目并解压。
2. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
3. 开启页面右上角的「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择本项目文件夹。
5. 打开网页，点击工具栏里的「阅行」图标，再点「开始阅读」。

安装后可以将阅行固定到浏览器工具栏，方便快速打开控制面板。

### 阅读本地 HTML

浏览器扩展详情页中开启「允许访问文件网址」：

- Chrome：`chrome://extensions` → 阅行 →「详情」→「允许访问文件网址」
- Edge：`edge://extensions` → 阅行 →「扩展选项/详情」→ 允许访问文件 URL

之后用浏览器打开 `.html` 或 `.htm` 文件，即可使用自动滚动。

## 使用

1. 点击扩展图标，设置速度、循环阅读和平滑滚动。
2. 点击「开始阅读」。弹出窗口会关闭，页面角落出现迷你「阅」图标。
3. 点击迷你图标可展开控件，暂停、继续或停止；点右上角「↗」可打开阅行正式窗口，「×」会停止阅读并关闭悬浮控件。拖动面板标题栏可调整位置。
4. 使用滚轮或键盘手动阅读时，自动滚动会暂停。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 开始或暂停 | `Alt + Shift + R` |
| 停止 | `Alt + Shift + S` |

可在 `chrome://extensions/shortcuts` 或 `edge://extensions/shortcuts` 修改快捷键。

## 权限与隐私

阅行使用浏览器本地存储保存偏好设置，通过活动标签页和脚本注入权限控制当前页面滚动。扩展不收集、上传或分析阅读内容。

本地文件阅读需要用户在浏览器扩展详情页手动开启文件网址访问权限。浏览器内部页面、扩展商店等受浏览器保护的页面不能注入脚本。
